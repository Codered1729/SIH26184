## Goal

## Tasks

### Task 1: Fix Hawkes Circular Benchmark

**Files modified**: `sentinel_prototype/sentinel/ml/experiments/validate_hawkes.py`

**Problem**: Ground-truth target ATM is selected with `weights = [math.exp(-d / 2.0) for _, d in nearby]`, which is identical to the spatial decay kernel the Hawkes ranker itself uses. This creates a tautological benchmark.

**Action**:
- Replace the weighted random choice with uniform random selection:
  ```python
  # BEFORE (circular — same kernel as Hawkes ranker):
  weights = [math.exp(-d / 2.0) for _, d in nearby]
  tot = sum(weights)
  probs = [w / tot for w in weights]
  target_atm = np.random.choice([a for a, _ in nearby], p=probs)

  # AFTER (honest — independent of ranker):
  # Ground truth: uniform random from nearby ATMs (independent of ranker kernel)
  target_atm = random.choice([a for a, _ in nearby])
  ```
- Remove the now-unused `weights`, `tot`, `probs` variables
- Update the docstring to clarify: "Ground truth ATM selected uniformly at random from nearby set — independent of Hawkes ranker's spatial kernel."
- Keep the static baseline comparison intact (it uses `baseline_rates`, not the spatial kernel)

**Acceptance criteria**:
- `validate_hawkes.py` does NOT contain `math.exp(-d / 2.0)` in the ground-truth selection section
- Contains `random.choice([a for a, _ in nearby])`
- Hit@3 drops from 74.6% (circular) to a lower honest figure

### Task 2: Apply Isotonic Calibration to Production CatBoost Model

**Files modified**: `sentinel_prototype/sentinel/ml/train_and_serialize.py`

**Action**:
After training all models and computing the holdout metrics (from Plan 07-01), add a calibration step for the primary model:

```python
from sklearn.calibration import CalibratedClassifierCV
from sklearn.metrics import brier_score_loss

# Calibration split: use last 10% of training data as calibration holdout
# (training data is X_train/y_train from Task 1 of 07-01)
cal_split = int(len(X_train) * 0.90)
X_cal_train = X_train.iloc[:cal_split]
y_cal_train = y_train[:cal_split]
X_cal_val = X_train.iloc[cal_split:]
y_cal_val = y_train[cal_split:]

# Re-fit primary model on cal_train only
primary_name = "CatBoost" if "CatBoost" in trained_models else list(trained_models.keys())[0]
primary_clf = trained_models[primary_name].__class__(**trained_models[primary_name].get_params())
primary_clf.fit(X_cal_train, y_cal_train)

# Calibrate on cal_val
calibrated_clf = CalibratedClassifierCV(estimator=primary_clf, method='isotonic', cv='prefit')
calibrated_clf.fit(X_cal_val, y_cal_val)

# Measure Brier improvement on holdout
raw_probs = trained_models[primary_name].predict_proba(X_test)[:, 1]
cal_probs = calibrated_clf.predict_proba(X_test)[:, 1]
brier_raw = brier_score_loss(y_test, raw_probs)
brier_cal = brier_score_loss(y_test, cal_probs)
print(f"Brier improvement: {brier_raw:.4f} → {brier_cal:.4f}")

# Store calibrated model in bundle
bundle["calibrated_model"] = calibrated_clf
bundle["calibrated_model_name"] = primary_name + "_isotonic"
bundle["brier_calibrated"] = brier_cal
```

**Acceptance criteria**:
- `CalibratedClassifierCV` imported in `train_and_serialize.py`
- `calibrated_clf` stored in bundle as `calibrated_model`
- Bundle contains `brier_calibrated` key

